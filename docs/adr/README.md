# Registros de decisiones de arquitectura (ADR)

Una decisión por archivo. Formato: contexto, decisión, alternativas
consideradas, consecuencias. Una decisión no se edita: si cambia, se escribe
un ADR nuevo que la supersede.

La excepción es un **error de especificación**: cuando lo que el ADR decidió no
era otra opinión sino algo equivocado, se corrige **en el mismo archivo**, con
una sección «Corrección» fechada que deja escrito qué decía, por qué estaba mal y
qué dice ahora. Un ADR nuevo diría la decisión correcta y perdería lo que más
vale: que se vea el cambio de opinión y su causa. Hoy es el caso del **ADR 0012**
(los ejes del relleno dependían del rango, corregido el 2026-09-11).
