Marcado: el texto de arriba se le manda a una sesión de Claude Code, que escribe el JSON de la consulta leyendo el catálogo. Sin marcar: se manda el JSON preparado de esta pregunta, sin ningún modelo de por medio.

Marcado: al cambiar la pregunta, las fechas o el departamento, el texto se reescribe con el preparado, y al agente se le manda ese texto más una línea "Filtros:" con las fechas y el departamento del formulario. Desmarcado: el texto es tuyo, nadie lo toca, y al agente se le manda solo eso: las fechas y el departamento del formulario NO se agregan (siguen valiendo para el camino sin agente).
